# React Portfolio Website 
I developed my own portfolio website with the help of the following React tutorial: https://youtu.be/hYv6BM2fWd8?si=-CF26tr1M65ZOcNt  

## About this project
Having completed many courses during my studies and developed a number of projects, I have decided to document my work in the form of a portfolio website.
Apart from that, I wanted to familiarize myself with React.

The Portfolio is separated into X section that will be explained in the following: 

## Navigation
The navigation bar contains a logo, 4 links and 2 buttons.
Home: will take you to the top of the page
Skills: will take you to the skills section 
Projects: will take you to the project section 

Github icon: will take you to my Github Account
Let's connect button: redirects you to an email service so you can send me an email
